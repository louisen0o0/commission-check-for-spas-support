Commission Check for Spas — Support

Commission Check for Spas is a local-first tool for checking membership-redemption service commissions before payroll.

What the app does

  1. Set the pay period.
  2. Import a Memberships report.
  3. Configure commission rules.
  4. Import a Service/Class Sales report.
  5. Review Overpaid, Underpaid, Correct, and Review Required results.
  6. Export CSV or PDF evidence when needed.

Important limitation

Commission Check for Spas verifies commissions. It is not payroll, tax, HR, POS, CRM, or scheduling software.

When source data is incomplete or a rule cannot be applied safely, the app marks the transaction Review Required instead of guessing.

Supported files

The initial release supports CSV and XLSX import.

This release accepts CSV and XLSX report files that you export yourself. It does not connect to, log into, or integrate with any named salon-management platform.

Your data

The app is designed to work locally on your device and does not require an account or a backend service.

See the Privacy Policy for current data-handling details.

Troubleshooting

A file will not import

  • The file must be CSV or XLSX.
  • Required columns must be present.
  • The file must remain within the app's safety limits.
  • Complete manual column mapping if report headers are not recognized.

The app intentionally fails closed instead of guessing required fields.

A transaction says Review Required

Review Required means the app does not have enough reliable information to assert a commission adjustment automatically. Check the membership record, staff rule, service row, and source report.

I changed a commission rule

Use Re-run Last Imported Report to create a new check with the current rules and pay period.

I want to remove local data

Use the data controls in Rules to clear check history or clear all local app data.
